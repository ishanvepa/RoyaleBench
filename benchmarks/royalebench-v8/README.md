# RoyaleBench v8

18 tasks: the exact union of `royalebench-v6@1` (14) and `royalebench-v7@1` (4).
Task IDs, instructions, runtime, references and grading retain their source bytes.
Score: mean binary source-task reward; this is an objective success rate.
See [the guide](../../docs/royalebench_v8.md) and `manifest.json` for provenance.
Rebuild with `uv run python -m cr_arena.build_v8` (requires Valkyrie access).
