# Run evidence

This directory keeps compact, reviewable evidence rather than every generated sandbox file. The v9 release retains its source manifest, publication and validation summaries, accepted reference actions, reports, and replay files needed by the dashboard. [`royalebench-v9/model-results.json`](royalebench-v9/model-results.json) summarizes the 12 complete Valkyrie model runs, per-task rewards, exact run IDs, source result checksums, and selected action sequences. The original result downloads remain local under the ignored `royalebench-v9/hosted-results/` directory and can be fetched again by run ID. The v8 reference actions, reports, and replays remain because `cr_arena.validate_v9` checks them before reusing a source reference. Earlier development cohorts retain summary records and explicitly cited examples; bulky duplicate telemetry, Docker captures, downloaded agent output, round-robin logs, and video renders were removed from the submission tree.

A new Valkyrie run writes downloaded results under `runs/`. Those outputs are ignored by Git by default. Review them locally, then commit only the summaries and representative traces needed to support a reported result with `git add -f`. The release-specific build, validation, and model comparison details are in [the v9 guide](../docs/royalebench_v9.md); re-running container validation regenerates the full local capture and negative-control artifacts. The published Valkyrie run IDs in the result record remain the source for hosted raw traces.
