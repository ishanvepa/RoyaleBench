# RoyaleBench v6

14 tasks: the exact union of `royalebench-v5@1` (10) and `royalebench-win@2` (4).
Task IDs, files, instructions, runtime, references and grading are unchanged.
The score is the mean binary source-task reward, so it is not an all-task match-win rate.
See [the guide](../../docs/royalebench_v6.md) and `manifest.json` for provenance.
Rebuild with `uv run python -m cr_arena.build_v6` (requires Valkyrie access).
